Как проходят занятия

Формат, удобный для семьи

A

Онлайн-уроки 2 раза в неделю

Преподаватель объясняет тему, ученик выполняет практические задания прямо на уроке. Длительность — 60–90 минут.

B

Домашние задания с проверкой

Работы загружаются в личный кабинет. Преподаватель проверяет код, ставит балл и пишет развёрнутый комментарий.

C

Записи и материалы

Все уроки и конспекты остаются в доступе, поэтому пропущенную тему всегда можно догнать без стресса.

Живой код

Учимся на реальном коде

Никакой «теории ради теории»: каждый урок заканчивается кодом, который ученик пишет сам. Преподаватель разбирает решение построчно и подсказывает, как сделать лучше.

  • Разбор кода каждого ученика в личном кабинете
  • Домашние задания приближены к реальным задачам
  • Постепенное усложнение без перегрузки
student.py — первый проект 
class Student:
    def __init__(self, name):
        self.name = name
        self.done = 0

    def submit(self, task):
        self.done += 1
        return f"{self.name}: сдано {self.done} заданий"

coder = Student("Мария")
print(coder.submit("ДЗ №1"))
